# Arctic Strategic Framing and Military Burden Replication Archive

This repository accompanies the manuscript **From Melting Ice to Alliance Security: Strategic Framing, NATO Exposure, and Military Burden in the Arctic**.

## What is included

- `scripts/`: Python scripts used for text extraction, content scoring, model-ready dataset construction, baseline models, and robustness models.
- `data/raw/`: original quantitative input files used in the panel construction.
- `data/processed/`: processed model-ready and content-score workbooks.
- `outputs/`: model-output workbooks generated by the scripts.
- `docs/`: content-analysis codebook, corpus index, and interpretation memo.
- `manuscript/`: current manuscript draft.

## Software

The analysis was run in Python using Anaconda Python 3.13. Main packages: pandas, numpy, statsmodels, openpyxl, pypdf, and python-docx.

## Quick replication

```bash
pip install -r requirements.txt
python3 run_models_only.py
```

The command reproduces the baseline, robustness, and article results workbooks in `outputs/`.

## Raw strategic documents

The GitHub-ready package lists public source URLs in `docs/DOCUMENT_CORPUS_INDEX.md`. The full PDF corpus is stored in the separate referee evidence pack to avoid repository-size and third-party document-rights issues.

## Important modelling note

The models should be read as screening and mechanism tests. The paper does not claim that sea-ice decline directly causes militarisation. The more defensible interpretation is a post-2022 alliance-security shift, supported by strategic-framing evidence.
